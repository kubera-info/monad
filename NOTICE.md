# This solutions requires:
* Visual Studio 2026 or newer (C#, VC++, HLSL, MSIX)
* DirectX 2010 June SDK, only for tools
* NMake
* vcpkg
* NuGet
* GIT submodules
* modern PowerShell
* .NET

## Applications can support the HDR, XBOX controller or Printer.

## Some programs are build with minimum the Shader Model 6.0, the D3D_FEATURE_LEVEL_12_0.
